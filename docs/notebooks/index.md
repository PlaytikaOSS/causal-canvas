# Notebooks

Tutorials and worked walkthroughs that complement the `examples/` configs.

- [01 — Generate synthetic data](01_generate_synthetic_data.ipynb) — build a small synthetic player-360 churn dataset using a hand-specified Bayesian network. Used as the input for `examples/wids/`.

The notebooks are mirrored from `notebooks/` in the repo root at site build time. To run them locally, start Jupyter from the repo root after `poetry install`:

```bash
poetry run jupyter lab notebooks/
```
